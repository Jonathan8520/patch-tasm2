The Amazing Spider-Man 2 · 1.3.1

Lecteur de sauvegardes

Ouvre un ud_*.sav pris dans le dossier Documents du jeu et lis ce qu'il contient. Tout est décodé ici même, dans la page — rien n'est envoyé nulle part.

Plusieurs fichiers à la fois, c'est possible. Sur ordinateur tu peux aussi les déposer ici.

Ce qu'il faut regarder

ud_QuestManager.sav est le fichier décisif : son deuxième entier porte le chapitre depuis le build chapter-save. Chapitre 0 → l'intro du tutoriel se relance. Chapitre ≥ 1 → elle est passée.

Les autres fichiers sont là pour le contexte : l'heure d'écriture dit quels objets le jeu a réellement sauvegardés pendant la session.
